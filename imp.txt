so we used setsockopt ... what it did was ... it told the kernel to relax its 
default rule and allow your server to re bind to the same port even if previous 
tcp connections are still in TIME_WAIT

SO_REUSEADDR tells the kernel to allow rebinding a port even if old TCP connections are still lingering in TIME_WAIT ... 
this solves “address already in use” during restart
